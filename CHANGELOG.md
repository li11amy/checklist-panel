# Changelog

## 1.0 — 2026-09-25

Initial public release.

- Show tasks from a Todoist project, saved filter, or manual filter query in the GNOME top panel.
- Complete tasks directly from the menu or open them in Todoist.
- Prefer the Todoist desktop app and fall back to the browser when no Todoist URI handler is installed.
- Position the indicator on the left, before the clock, after the clock, or on the right.
- Optional task count, panel spacing, menu title, task limit, and refresh interval.
- Store the Todoist API token in GNOME Keyring / Secret Service.
- Use the saved filter's Todoist account language automatically; manual queries can select a supported filter language.
- Keep long task lists from hiding footer actions.
- Include compact error/empty states and a few harmless title-based easter eggs.
